# whsun-viz image requirements.
#
# One image serves every mount: /gliquid/ (static + a Dash ternary plotter),
# /cogito-cohp/, /rsm/ and /tb/ (Dash), plus the static /cogito/ and /vr/ trees.
# (The COHP app is mounted at /cogito-cohp/ -- there is no /cohp/ URL.)
# Everything below is shared, so a bound here affects all of them.
#
# WHY THE pydantic-2 JUMP: mp-api and emmet-core are pydantic-2 only. That makes
# `pydantic<2` and therefore `fastapi<0.69` impossible. Modern Starlette has REMOVED
# `fastapi.middleware.wsgi.WSGIMiddleware`, so the ASGI->WSGI bridge for the Dash
# sub-apps now comes from a2wsgi (see main.py).

# --- the gliquid package ------------------------------------------------------
# Replaces the vendored November-2025 fork that used to live in this app's own
# scripts/ directory (phase_diagram.py, binary.py, load_binary_data.py, hsx.py,
# config.py -- 7,096 lines).
#
# ##############################################################################
# ## !! THE PIN BELOW IS A LOCAL-WHEEL PIN. DO NOT PUSH THIS FILE AS IT IS. !! ##
# ##############################################################################
#
# `0.1.1.dev8+g24546dfb7` is a LOCAL DEVELOPMENT BUILD -- a hatch-vcs
# `git describe` version off an unreleased commit. It exists only in the gitignored
# ./wheels directory on the machine that built it. Consequences, in order of how
# much they will hurt:
#
#   1. A CLEAN CLONE OF THIS REPO CANNOT BUILD THE IMAGE. There is no wheel to find
#      and no such version on any index, so `pip install` fails outright. Anyone who
#      clones this today must first rebuild the wheel with the recipe below.
#   2. This version can never be resolved by anyone without the gliquid_python
#      checkout at that exact commit, so CI and any other contributor are blocked.
#
# BEFORE PUSHING: cut a real gliquid release to PyPI and repoint this line at it
# (e.g. `gliquid==0.1.1`), then delete the --find-links plumbing from the Dockerfile.
# The user is deliberately holding this pin until two in-flight package fixes land, so
# that ONE release covers them; do not repoint it piecemeal or bump it to another dev
# build.
#
# Rebuild the wheel from the gliquid_python checkout with:
#
#     git clone <gliquid_python> /tmp/gliquid && cd /tmp/gliquid
#     git checkout cache-layout            # 24546df; `git describe` -> v0.1.0-8-g24546df
#     python -m build --wheel --outdir <whsun-viz>/src/wheels
#
# The clone is load-bearing: hatch-vcs derives the version from the git tag, and a
# `git archive` (no .git) would silently stamp the 0.0.0 fallback instead.
gliquid==0.1.1.dev8+g24546dfb7

# --- ASGI / web stack ---------------------------------------------------------

# --- Dash / Flask sub-apps ----------------------------------------------------
# Flask, Werkzeug, itsdangerous, Jinja2, MarkupSafe, blinker and click are left to

dash>=2.18,<3

# plotly floor is gliquid's (5.18's express layer breaks on pandas 3); the <6 ceiling

numpy>=1.26,<3

matplotlib>=3.10
openpyxl>=3.1.5

# --- Materials Project / MPDS -------------------------------------------------

# Ceiling is measured and load-bearing, not hygiene: emmet-core 0.87.1 resolves
# emmet.core.io.pymatgen.__getattr__ onto pymatgen.core.entries, a module current
# pymatgen no longer has, which breaks every live MP fetch. gliquid pins the same
# bound; it is repeated here so removing it needs the same evidence twice.

#
# mpds_client is DELIBERATELY ABSENT. It was here for the vendored fork's live MPDS

# container can talk to MPDS. It cannot: there is no key and no code path.
